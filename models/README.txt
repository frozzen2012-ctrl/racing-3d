cars.bin — модели машин для игры.

Источник: «Cars - Low Poly Massive Car Pack» от RG Poly
https://rg-poly.itch.io/cars-low-poly-massive-car-pack
Лицензия набора: Creative Commons Zero v1.0 Universal (CC0), указание автора не требуется.

Файл собран скриптом tools/bake-cars.mjs из версии набора для Godot (glTF):
кузов и колёса каждой машины склеены в одну сетку, цвета из палитры перенесены в вершины.
Список моделей — tools/car-models.json. Пересборка: npm run bake:cars
(исходный набор должен лежать в _assets_src/cars-godot, в репозиторий он не входит).
